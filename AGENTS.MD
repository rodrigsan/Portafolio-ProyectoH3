# Agente de Desarrollo - Portafolio Personal Angular (H3)

Este archivo documenta la estructura, configuración e instrucciones del agente de Inteligencia Artificial para el desarrollo de la Evaluación Continua H3.

## 1. Información General del Proyecto
- **Tema del Portafolio:** Portafolio Personal Temático - "Yo soy Batman" (Bruce Wayne)
- **Framework:** Angular
- **Estilos & UI:** CSS3, Bootstrap 5, Bootstrap Icons
- **Plantilla Base:** iPortfolio (BootstrapMade)
- **Modo de Operación:** Single Page Application (SPA)

## 2. Estructura del Código y Recursos
- `src/app/app.html`: Vista principal con navegación fija lateral (`#header`) y secciones integradas.
- `src/index.html`: Carga de fuentes, scripts JS de la plantilla e íconos de Bootstrap.
- `src/styles.css`: Estilos globales y reglas de visibilidad para animaciones.
- `public/assets/img/`: Directorio con las imágenes del proyecto (`bruce.jpg`, `imagen1.jpg`, `batmantood.jpg`).

## 3. Secciones Implementadas
1. **Hero:** Presentación interactiva y portada principal.
2. **About:** Biografía, perfil táctico y datos de contacto.
3. **Resume:** Historial de entrenamiento (Liga de las Sombras, Criminología) y experiencia operativa.
4. **Portfolio (Gadgets):** Tarjetas de equipamiento tecnológico (Batmóvil, Batarang, Batcomputadora).
5. **Services:** Servicios tácticos (Patrullaje Nocturno, Investigación Forense, Ciberseguridad).
6. **Contact:** Formulario y canal de emergencias (Batiseñal).

## 4. Directivas de Mantención
- Preservar el diseño responsivo en dispositivos móviles y de escritorio.
- Mantener las rutas de imágenes relativas dentro de la carpeta `assets/img/`.
- Garantizar que la arquitectura en Angular sea limpia y modular.
